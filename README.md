# Energy explorer

## Set up

Add your CPE and `aat` cookie value inside a `.env` file and run `pnpm dev`

The `aat` cookie value can be found once logged in to [E-Redes](https://balcaodigital.e-redes.pt/login)

## Sources

- E-Redees for energy consumption
- ERSE for electricity prices
- Electricity Map (?) for CO2 emission
- Entsoe (?) for electricity prices
